# NetSpeedTaskbar

常驻 Windows 任务栏的小监控面板：**网速 / 内存 / CPU、GPU 温度 / AI Token 速度**，
顺带内置截图标注、OCR 取字、截图翻译和区域录屏。

适用于 Windows 10 / 11（64 位）。

---

## 安装

1. 从 [Releases](https://github.com/q455040355-del/NST/releases) 下载 zip，解压到任意目录。
   请连 `models\` 一起解压——那是取字用的模型，只拷 exe 会用不了「取字」。
2. 双击 `netspeed.exe`。面板贴在任务栏托盘旁，托盘出现图标。
3. 想开机自动运行：设置 → 左下角「开机自启」。
4. 升级：设置 → 右下角「检查更新」，确认后自动下载替换并重启。

- 绿色软件，配置在 `%LOCALAPPDATA%\NetSpeedTaskbar\`，删掉即恢复默认。
- 单实例运行：重复启动不会再开一个面板。

## 面板

| 视图 | 显示 |
| --- | --- |
| 网速 | 实时上传 / 下载 |
| 内存 | 已用 / 总量 |
| 温度 | CPU 与 GPU（能读到时附带 GPU 功耗） |
| AI | 实时 Token 速度 + 今日累计（输入 + 输出） |

- **左键点一下**切换视图（会记住）；**按住拖动**可挪到任务栏任意位置。
- **悬停面板上面一行**看当前占上传带宽的进程，**下面一行**看下载；
  任何视图都有效，需要先在右键菜单开启「进程明细」。
- **右键**打开菜单：视图切换、底部指示条、进程明细、用量历史、设置、
  截图 / 取字 / 录制、吸附到任务栏、隐藏面板、退出。
- **托盘图标**：面板被隐藏时左键单击唤回，否则左键打开菜单；右键也是菜单。
- **底部指示条**：内存占用 / Token 速度 / 关闭，鼠标停上去有说明。
- 全屏程序（游戏、视频）在前台时面板自动隐藏并暂停采集，退出全屏自动恢复；
  手动「隐藏面板」后需要点托盘唤回。
- 多显示器下贴住所在屏幕的任务栏；设置、历史等窗口开在鼠标所在屏幕。

## 设置

右键 →「设置…」，或运行 `netspeed.exe --settings`。左列是显示与 AI 统计，右列是截图取字与翻译。

| 项目 | 说明（默认） |
| --- | --- |
| 字号 | 小 / 标准 / 大 / 特大（标准） |
| 面板宽度 | 拖动滑杆，实时生效 |
| 底部指示条 | 内存占用 / Token 速度 / 关闭 |
| 网卡 | 自动（全部合计）或指定单块网卡 |
| 刷新间隔 | 0.5 / 1 / 2 秒（0.5 秒） |
| AI 统计 | 总开关（默认关）+ 六个来源勾选 |
| 截图、取字、录制 | 各自的开关和快捷键，点快捷键胶囊即可重录 |
| 录制 | 画质 50 / 65 / 80，时长 10 / 20 / 30 秒，帧率 自动 / 30 / 60 / 120 |
| 翻译 | 总开关、服务商、API Key、模型、Base URL、目标语言 |
| 页脚 | 开机自启、检查更新、完成 |

改动即时生效，没有「确定 / 取消」。键盘可用 `Tab` / `Shift+Tab` 切换控件，
方向键改值，`空格` / `回车` 拨开关，`Esc` 关闭窗口。

## 截图与标注

按 **`Ctrl+Shift+A`**（可在设置里改）：

- 全屏冻结压暗。鼠标下的窗口自动高亮，**单击直接截这个窗口**；也可以拖拽自由框选。
- 不拖时跟随一个 **4 倍放大镜**，显示像素网格、坐标和色值，`Ctrl+C` 复制色值。
- `Esc` / 右键取消，`Enter` 确认。编辑窗按原位置 1:1 打开。
- 工具：矩形 `R`、正方形 `Shift+R`、椭圆 `O`、直线 `L`、箭头 `A`、画笔 `B`、
  高亮 `H`、聚光灯 `P`、序号 `N`、马赛克 `M`、橡皮 `E`、文字 `T`；
  工具栏上还有滚动截图、旋转、美化、OCR、翻译和浓淡；
  撤销 `Ctrl+Z`、重做 `Ctrl+Y`。
- **缩放**：滚轮或 `+` / `-`（20%~600%），`Ctrl+0` 复位；没选工具时左键拖动就是平移。
- **滚动截图**：点工具栏「滚动截图」，自己用滚轮往下（或往上）滚，程序自动拼接；
  浮层上 `✓` 结束并生成一张长图，`×` 直接丢弃。
- **贴图**：把结果钉在最上层，右键、双击或 `Esc` 关闭。
- **输出**：`Enter` 或 `Ctrl+C` 复制到剪贴板，`Ctrl+S` 另存为 PNG，`Esc` 关闭。
  「美化」只在复制、保存、贴图时生效。
- 用远控软件时，热键由被控端响应，不会两台机器同时弹截图。

## 取字（OCR）与翻译

- **取字默认关闭**，先在设置里打开。之后：
  - `Ctrl+Shift+O` 先截图，再框选取字；
  - 或在截图编辑窗点「OCR」，只识别框选的区域（不框就是整张图）。
- 结果窗里文字可选中复制，识别完也会自动进剪贴板。
- **认出表格时可整表复制**，粘到 Excel / WPS / Word 里直接落格；
  三列及以上默认按表格复制，两列时用结果窗底部的「复制表格」按钮手动切换。
- **翻译默认关闭**，先在设置里填好服务商、Key 和模型，可点「测试连接」。
  截图编辑窗点「翻译」后框选要翻的内容：
  本地 OCR 出文字后，只把**文字**发给 ChatGPT 或 DeepSeek。
- 翻译结果窗支持「整段 / 逐句 / 只取字」三种看法，逐句可单句复制；
  目标语言可选 中文 / English / Srpski (lat.)。
- API Key 只保存在本机 ini 里。取字需要 exe 旁边的 `models\` 目录。

## 录屏

按 **`Ctrl+Shift+G`**（可在设置里改，也能从右键菜单「录制区域 MP4…」进）：

1. 框选一块区域，确认后开始录制。
2. 再按一次热键，或点右上角 ✔ 结束。
3. 结束**默认复制到剪贴板**（MP4 文件 + 首帧图片），能直接粘到微信、QQ、浏览器；
   想存成文件就点 ✔ 左边的保存图标。

画质、时长（10 / 20 / 30 秒）、帧率在设置里选；输出最高 1080p。
边框和控制条画在选区外侧，不会录进画面；画面里保留鼠标指针。

## Token 用量历史

右键 →「Token 用量历史…」（开启 AI 统计后才有），或运行 `netspeed.exe --history`。

- 区间：今天 / 昨天 / 7 天 / 30 天 / 全部；今天和昨天按小时展示。
- 来源可多选筛选，设置里没开的来源不会出现，上次的选择会记住。
- 四张卡片：输出、输入、请求（含缓存命中率）、平均速度。
- 下方是按来源堆叠的柱状图和每日明细表（请求、输出、输入、平均速度、峰值、主要模型）。

## AI 统计的数据来源

只读取本机这些工具自己的会话数据，**不上传任何内容**：

OpenCode、DSH、WorkBuddy、WorkBuddy AI、Claude Code、Codex。

- 默认关闭：关着时不读文件、不起线程，面板也不出现 AI 视图。
- 打开后常驻累计，停在别的视图也照样统计；没装的工具自动跳过。
- 「今日」= 输入 + 输出 Token，按消息去重。
- 面板只统计设置里勾选的来源，历史窗口有自己的来源筛选，两边对不上时先看这里。

## 常见问题

- **面板不见了**：打游戏 / 看视频时全屏自动隐藏属于正常；否则左键点托盘图标，
  或右键菜单 →「吸附到任务栏」。
- **取字提示找不到模型**：把 `models\` 放到 `netspeed.exe` 旁边。
- **进程明细没数据**：需要管理员权限，第一次打开会弹 UAC。拒绝后可在右键菜单点「重新连接进程明细」。
- **GPU 温度显示 `--`**：需要 NVIDIA 显卡驱动自带的 `nvidia-smi`；CPU 温度个别机器读不到也会显示 `--`。
- **截图热键没反应**：检查设置里对应开关是否打开、快捷键是否被其他程序占用；远控时热键在被控端生效。
- **字体**：优先「苹方」，没有则「Noto Sans SC」，再没有用「微软雅黑 UI」；
  想强制指定可设环境变量 `NST_UI_FONT`。
